## 2. Известные проблемы и незавершённое

### Баги и риски

- **OpenRouter (резерв LLM) отвечает 404** — модель или ключ (по `PROJECT.md` §11).
- **`pollinations.ai` с 20.11 отдаёт 402**, но дефолт `TG_IMAGE_PROVIDER="free"`; есть обход через Cloudflare, дефолт не переключён.
- **Ключ сообщества ВК для загрузки фото отклоняется** (ошибка 27) — используются готовые шаблоны.
- **Секреты из `.env` попадали в логи ассистента** (токен бота, ключи LLM/Tavily, пароль админки) — перевыпуск не подтверждён.
- **Гонки JSON**: бот и сайт пишут в одни файлы — возможна потеря одной отметки (`QUESTIONS.md`).
- **Лимит Telegram 4096 символов** — длинные тексты корзины обрезаются.
- **Единицы корзины**: яйца в штуках, остальное в г/мл; ВкусВилл продаёт не всё по весу → «не нашёл».
