# 🍲 Кухонный помощник

Подбирает рецепт по анкете (тип питания, цель по КБЖУ, продукты, исключения, время, порции, техника), считает калории и КБЖУ
на порцию, показывает, где купить продукты (Пятёрочка, ВкусВилл, Лавка, Купер). Есть меню на день и план питания на 3 дня
(корзина продуктов + рецепты по дням из реального остатка). Работает как **Telegram-бот** и как **сайт** (устанавливается на
телефон как приложение, умеет PDF), оба на одном ядре.

**Где что читать:**
- `PROJECT.md` — полное описание: архитектура, файлы, как всё работает, что сделано и что осталось (можно целиком дать любому ИИ-чату).
- `DEPLOY_WEB.md` — пошаговый запуск сайта на https://menu.pump-um.ru.
- `.env.example` — какие настройки нужны (с пометками «обязательно / добавь / по желанию»).
- `QUESTIONS.md` — открытые вопросы и принятые решения.

**Быстрый старт для разработки** (Windows, PowerShell):
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
python bot.py
python -m uvicorn web_api:app --port 8123
```
`.env` заполни своими ключами (бот: `python bot.py`; сайт: `http://127.0.0.1:8123`).

**Деплой на сервер:** двойной клик по `update_cooking.bat` (перед этим посмотри `git status`).
