# 🍲 Кухонный бот-помощник

Telegram-бот, который по анкете (кухня → продукты → исключения → время → порции →
техника) ищет рецепты в интернете (DuckDuckGo, бесплатно) и с помощью ИИ (Groq или
OpenRouter, бесплатные модели) подбирает конкретный рецепт: список продуктов с
количествами под нужное число порций и пошаговую инструкцию под выбранную технику
приготовления.

## 1. Установка

```bash
cd kitchen_bot
python -m venv venv
# Windows:
venv\Scripts\activate
# Mac/Linux:
source venv/bin/activate

pip install -r requirements.txt
```

## 2. Настройка ключей

Скопируй `.env.example` в `.env` и заполни:

```bash
cp .env.example .env
```

- `BOT_TOKEN` — токен от @BotFather (как у первого бота).
- `LLM_PROVIDER` — `groq` или `openrouter` (что из них у тебя уже есть ключ).
- `GROQ_API_KEY` — ключ с https://console.groq.com/keys (бесплатно, быстрый).
- `OPENROUTER_API_KEY` — ключ с https://openrouter.ai/keys (бесплатно, модели с
  пометкой `:free` в названии, например `meta-llama/llama-3.3-70b-instruct:free`).

Поиск рецептов работает через `duckduckgo-search` — ключ не нужен.

## 3. Запуск

```bash
python bot.py
```

Дальше в Telegram: `/start` → пройти анкету → получить рецепт.

## Структура проекта

```
kitchen_bot/
├── bot.py          # точка входа, вся логика анкеты (FSM)
├── config.py       # чтение .env
├── states.py       # состояния анкеты
├── keyboards.py    # inline-кнопки
├── search.py       # поиск рецептов в интернете (DuckDuckGo)
├── ai.py           # вызов LLM (Groq/OpenRouter)
├── prompts.py       # системный и пользовательский промпты для ИИ
├── requirements.txt
└── .env.example
```

## Как дорабатывать промпты

Все "мозги" бота — в `prompts.py`. Именно там стоит делать ресёрч и улучшать
качество: правила аюрведической/классической кухни, формат вывода, точность
количеств. Логику бота (`bot.py`) трогать для этого не нужно.

## Возможные доработки

- Добавить сохранение истории рецептов пользователя (SQLite).
- Добавить кнопку "Другой вариант" — перегенерировать рецепт с теми же
  параметрами, но другим поисковым запросом/temperature.
- Добавить голосовой ввод предпочтений.
- Деплой на сервер — так же, как разворачивал первого бота.
